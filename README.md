# Cortex Code

**Cortex Code** — консольный AI-помощник для разработчиков, работающий через OpenRouter. Умеет читать, создавать и редактировать файлы, управлять рабочей папкой, поддерживает несколько чатов и показывает прогресс выполнения запросов в реальном времени.

## Возможности

- Чат с AI (OpenRouter, модели на выбор, например openrouter/owl-alpha)
- Управление файлами — создание, редактирование, чтение, удаление, запуск Python-скриптов
- Умное редактирование — минимальные правки через <<<REPLACE:...>>> и <<<APPEND:...>>> (как в Cursor)
- Автоматический контекст — AI сам подхватывает нужные файлы из запроса
- Смена рабочей папки — командами /cd, /directory или прямо в диалоге ("C:\Projects\myapp сделай...")
- Несколько чатов — создавайте, переключайте, переименовывайте, удаляйте беседы
- Прогресс-бар — визуальная индикация обработки запроса
- Очистка контекста — команда /clear
- Сохранение настроек — имя, API-ключ, модель в config.json

## Требования

- Python 3.9+
- API-ключ OpenRouter (https://openrouter.ai/keys)
